# Class content architecture

Each class has its own directory. Within a class, every subject has its own directory; every chapter has its own directory; every topic is an independent module directory. Chapter resources (examples, exercises, formulas, 2D diagrams, 3D models, photographs and animations) are kept separately from topic theory.

Class 11 is the first migration target. Class 12 and Mock Test/PYQ runtime are protected from this migration until separately approved.
